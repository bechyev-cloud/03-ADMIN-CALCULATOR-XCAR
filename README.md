# XCAR Super Admin PWA
PWA-панель управления, адаптированная для мобильных экранов, включая Samsung S25 Ultra.

Панель открывается в режиме просмотра без входа. Изменяющие действия защищены логином/паролем сервера.

Функции: пользователи, подписки, заявки, реквизиты, QR, сервер, чаты, рассылки на главный экран, резервные копии и светлая/тёмная тема.
